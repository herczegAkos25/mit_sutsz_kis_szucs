# 🥐 Mit sütsz, kis szűcs?

Egy egyszerű, letisztult webes receptkezelő alkalmazás, amely segít böngészni a finomabbnál finomabb receptek (édes és sós sütik, főételek, tradicionális fogások) között, valamint lehetőséget biztosít új receptek és képek kezelésére.

## 🛠️ Felhasznált technológiák

* **HTML5** – UI szerkezet és űrlapok
* **CSS3 (Grid & Flexbox)** – Reszponzív elrendezés és dizájn
* **JavaScript (ES6+)** – Dinamikus DOM-generálás, receptek kezelése és szűrése
* **JSON / LocalStorage** – Adattárolás és receptadatok struktúrája

---

## 🚀 Futtatás helyi környezetben

Az alkalmazás futtatásához nincs szükség külön szerveri környezetre:

1. **Klónozd a repository-t:**
   ```bash
   git clone [https://github.com/herczegAkos25/mit_sutsz_kis_szucs.git](https://github.com/herczegAkos25/mit_sutsz_kis_szucs.git)
   Nyisd meg a projektet:```
2. Keresd meg az index.html fájlt a gyökérkönyvtárban, és nyisd meg bármelyik böngészőben (Chrome, Firefox, Edge).

---

## 🥐 Funkciók & Kategóriák
📖 Receptböngésző: Receptkártyák megjelenítése képpel, hozzávalókkal és elkészítési lépésekkel.

🥨 Sós sütik & Főételek: Különböző kategóriák szerinti csoportosítás (pl. sajtos pogácsa, húsos ételek, desszertek).

➕ Új recept feltöltése: Űrlap segítségével új receptek és képek hozzáadása.
